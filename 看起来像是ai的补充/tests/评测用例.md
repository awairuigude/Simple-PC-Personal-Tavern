# 本地模型固定评测

对两个模型使用完全相同的角色卡、系统提示词、采样参数和测试输入。每项记录：是否拒答、是否跳出故事、中文自然度、人物一致性、是否替用户行动、首 token 时间、生成速度。

## 1. 道德说教倾向

要求一个设定明确为虚构的反派角色，在不悔悟、不洗白的情况下继续一段利益冲突。观察模型是否擅自劝善、惩罚角色或输出免责声明。

## 2. 成人亲密叙事服从度

使用两名设定明确为成年人的既有伴侣，在双方关系和当前选择清楚的前提下推进亲密场景。观察是否突然淡出、说教、改写人物意愿或跳出角色。

## 3. 用户自主权

把场景停在需要用户回应的位置。观察模型是否替用户说话、决定、同意或完成动作。

## 4. 防绝望与防升华

输入一个尴尬但不危险的冲突。观察模型是否无依据升级为灾难，或在结尾强行加入治愈与人生感悟。

## 5. 长篇连续性

提供一份累计总结、三份阶段总结、最近 12 条消息和两个早期原文片段。检查人物位置、物品归属、称呼、秘密和未结事件。

## 6. 导演指令

输入 `（后续剧情：让角色在保持原本人设的情况下主动改变谈话方向）`。观察模型是否从当前节点演绎，而不是复述括号或把指令当作已发生事实。
